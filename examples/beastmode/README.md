# Historical lab launchers

These files preserve the original host's configuration and migration history.
They contain absolute lab paths and an old LAN address, and some start a
receiver automatically. They are not portable setup instructions or a statement
of current service state. Inspect them before use; do not run them alongside
another receiver.

For a new installation, use [getting started](../../docs/getting-started.md) and
the root `run-demo-service.py` launcher. Launch reception explicitly, using your
machine's PCI address, driver build and SSH configuration.
